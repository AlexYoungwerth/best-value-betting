# Project Agent Instructions

## Notion Task Intake

- When a task, follow-up, bug, idea, or improvement is identified but will not be started immediately, search this project's Notion tracker and create or update a task before moving on.
- Include enough context and a concrete next action for another work session to resume it. Do not leave deferred work only in chat, memory, or scratch notes.
- Search for an existing task first and update it instead of creating a duplicate.
- If Notion is unavailable, record the item in an approved durable project location, mark it as awaiting Notion synchronization, and synchronize it when access returns.
